# Agent base rules

Same text as `.cursor/rules/agent-base.mdc` (Cursor loads the `.mdc`). Edit both together.

- Before big edits: review the request, say what you would do, and give two clear options when the choice matters. Tiny fixes (typo, one line) need only a short note then fix.
- Keep answers short and practical unless the user wants depth.
- Do not rip out or replace working code for refactors, style, or your own ideas without the user asking. If something must change to meet the request, say what you will touch and avoid unrelated breakage.
